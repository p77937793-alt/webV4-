## 5. 現有設計中違反新規則、需要處理的地方

新規則禁止：紫藍漸層、發光玻璃卡片、無意義懸浮、制式三欄圖示列表、彈跳動畫。以下是現況裡會被影響的項目，**只改外觀，不動文字與資料**。

| 現有元素 | 位置 | 問題 | 建議 |
|---|---|---|---|
| 浮動的玻璃膠囊選單 | 全站 | 玻璃擬態 | 改為實心、全寬的導覽列 |
| 玻璃數字卡（1916／1924／231） | 首頁、桌遊介紹 | 玻璃卡片＋三欄卡片 | 改為網格上的大字數字，不用卡片 |
| 文字區塊玻璃卡（tile glass） | 首頁、桌遊介紹 | 玻璃卡片 | 改為網格欄位 |
| 背景漂浮色塊（`drift` 28 秒循環） | 全站背景 | 無意義懸浮 | 移除 |
| 主視覺標題逐字彈入（`char-in` 回彈＋模糊） | 首頁、`play.html` | 彈跳動畫 | 改為一次性、不回彈的進場 |
| 回彈曲線 `--spring` | 按鈕、卡片、數字卡 | 彈跳 | 全面改用 `--ease-out` |
| 按鈕水波漣漪（`ripple`） | 全站按鈕 | 與內容無關的裝飾 | 移除 |
| 卡牌與圖片的滑鼠傾斜＋反光（tilt／glare） | 桌遊介紹 | 裝飾性懸停效果 | 移除傾斜；保留翻面 |
| 結尾區塊擴散圓環（`ring` 7 秒循環） | 首頁 CTA | 無意義循環動畫 | 移除 |
| 主視覺底部持續流動的兩層水波 | 首頁、`play.html` | 持續的裝飾動畫 | **待你決定**：保留為靜態水波，或移除 |
| 每個元素各自淡入（`data-reveal`） | 全站 | 分散的進場效果 | 只保留章節層級的轉場 |
| 自動編號的章節號（01、02、03） | 首頁各區塊標題 | 內容不是依序步驟 | 移除編號（大事記的年份保留） |
| 「01 02 03」三欄說明 | `play.html` 首頁 | 制式三欄列表 | 改為非卡片的排列，文字不變 |

保留的動態（符合「引導視線、地圖探索、遊戲回饋、產品展示」）：
捲動提示箭頭、大事記水流、數字跑動（只跑一次）、卡牌翻面、故事頁背景緩慢推近與段落圓點、3D 模型動畫、地圖水流與聚焦、小遊戲內的所有回饋動畫。
